# Lush Cave

A cave platformer. Find the black door in each cave, and the key that opens
it. Every cave is generated fresh from a random seed.

Play it: https://milosarcade.com/lushcave/

## Controls

Keyboard only.

| Key | Action |
|---|---|
| A / D | Move |
| Space | Jump (hold for height); swim up |
| Shift | Dash |
| W / S | Climb big vines; swim |
| M | Map |
| L | Mushroom hat |
| R | Reroll the level |
| Esc | Back to the menu |

Hold toward slimy walls to cling, then jump to wall-jump. Do not linger in lava.
